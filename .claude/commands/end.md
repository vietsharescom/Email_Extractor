# /end — Kết thúc phiên làm việc (Final Project AASD 4016/4017)

Khi Andy gõ "end" / "kết thúc" / "cuối phiên" trong project này:

1. Tự tóm tắt việc đã làm trong phiên (không cần Andy nhắc lại).
2. Cập nhật `PROJECT_STATE.md` — sửa đúng phần thay đổi thật (không viết lại toàn bộ
   file): trạng thái dataset, trạng thái dữ liệu thật, việc tiếp theo, câu hỏi mở.
3. Thêm 1 mục mới lên ĐẦU `CHANGELOG.md`, đúng format các mục trước (ngày + gạch đầu
   dòng ngắn gọn).
4. Báo cáo ngắn gọn cho Andy: đã làm gì phiên này, còn gì mở, phiên sau nên bắt đầu
   từ đâu.

KHÔNG commit/push git khi Andy chưa xác nhận (theo đúng quy tắc global).
