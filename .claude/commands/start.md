# /start — Bắt đầu phiên làm việc (Final Project AASD 4016/4017)

Khi Andy gõ "start" / "bắt đầu" / "s" trong project này:

1. Đọc toàn bộ `PROJECT_STATE.md`.
2. Đọc mục mới nhất (trên cùng) trong `CHANGELOG.md`.
3. Tóm tắt cho Andy trong tối đa 10 dòng: đang ở đâu, việc tiếp theo ưu tiên là gì,
   có câu hỏi mở nào cần Andy quyết không.
4. Hỏi Andy muốn làm gì trong phiên này — KHÔNG tự ý bắt đầu code/sinh dataset/redact
   file khi chưa xác nhận.

Không đọc file dữ liệu cá nhân thật (`data/Financial Personal`, `data/Business`,
`data/Immigration`...) trừ khi Andy yêu cầu trực tiếp trong phiên.
